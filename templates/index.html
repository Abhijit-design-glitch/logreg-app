Step 4 — How Logistic Regression Works

1. Linear combination

z = w₁x₁ + w₂x₂ + … + wₙxₙ + b

Each feature x is weighted by w. The sum + bias is a real number z ∈ (-∞, ∞).

2. Sigmoid function

σ(z) = 1 / (1 + e-z)

Squashes z into (0, 1) — interpreted as a probability.

3. Decision rule

ŷ = 1 if σ(z) ≥ 0.5 else 0

4. Multiclass — One-vs-Rest

Train one binary classifier per class, pick the class with highest probability.
